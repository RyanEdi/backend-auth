# Auth Service

Servico de autenticacao, cadastro, administracao e notificacoes por email.

## Scripts

- npm run dev
- npm run build
- npm run start

## Variaveis de ambiente

- AUTH_SERVICE_PORT (default 3334)
- SESSION_SECRET
- DB_HOST, DB_PORT, DB_USER, DB_PASSWORD, DB_NAME
- FRONTEND_URL
- SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS
- ADMIN_CPFS

## Publicar como novo repositorio

1. git init
2. git add .
3. git commit -m "init auth-service"
4. git branch -M main
5. git remote add origin <URL_DO_REPO>
6. git push -u origin main
